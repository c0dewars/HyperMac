# HyperMac icon

Generated with the built-in image generation tool, then mechanically resized and encoded to PNG/ICNS with Pillow. The committed ICNS is used by the macOS build; Pillow is not a build dependency.

Prompt:

Create a polished macOS application icon for HyperMac, a lightweight multi-monitor tiling window manager. Single square 1024x1024 icon asset, no lettering, no words, no mockup, no surrounding scene. A centered rounded-square deep midnight-indigo tile with generous transparent outer margins. Inside, three crisp luminous window panes arranged in an elegant asymmetrical tiled layout suggesting a subtle H: tall cyan left pane, a small violet upper-right pane, a mint lower-right pane, with consistent dark gutters. Premium restrained glass depth and soft highlights, strong simple silhouette recognizable at 32 pixels, clean edges, not busy, no tiny symbols. Entire icon visible, straight-on orthographic. True transparent background outside the rounded-square tile.
